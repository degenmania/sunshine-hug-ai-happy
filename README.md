# Make the AI Judge Happy

An entry for the make.fun bounty "Make the AI judge happy" (ai-happy-01).

`main.py` (Python 3.13, standard library only) copies the bundled original
illustration `happy.png` — a laughing golden retriever puppy hugging an
orange kitten in a sunflower meadow under a rainbow and a smiling sun —
to `/output/entry.png`.

The image is 1024 x 1024 PNG, under 1 MiB. The program uses no network and
no randomness, so repeated runs write byte-identical output.
